# Macro

Call `lonora_calendar`, `lonora_headlines`, or delegate `macro-news-analyst`. Report only what those tools return. If a feed is not ok, say that feed is unknown. An empty headline list is a quiet window only when the headline read succeeded. Do not fill a quiet week, a headline, or a central-bank decision from memory.
